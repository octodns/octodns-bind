Migrate to octoDNS's new RDATA API (`Rrset`/`to_rrset`/`from_rrsets`), replacing the deprecated `Rr`/`record.rrs`/`Record.from_rrs` calls. Requires `octodns>=1.22.0`. `zone_records()` on `ZoneFileProvider` and `AxfrPopulate` now returns grouped `Rrset` objects instead of one `Rr` per rdata; TXT/SPF quoting and chunking is now delegated to core's `to_rdata_text()`.
